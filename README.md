# Niki's Neighborhood

A desktop-first, buildless Three.js portfolio, inspired by the miniature city composition and animated opening of Silicon Valley.

## Preview

Run `python3 -m http.server 4173 --directory dist`, then open http://localhost:4173.

## Edit

- `dist/content.js` — six districts, project descriptions, and photo captions.
- `dist/city.js` — procedural 3D architecture, motion, camera, and picking.
- `dist/app.js` — drawers, directory search, photo viewer, and controls.
- `dist/style.css` — page layout and visual design.
- `dist/assets/` — optimized copies of selected provided photographs.
- `dist/vendor/` — pinned Three.js 0.180.0 modules and fonts.

Portfolio copy derives from the supplied activity list, application activity entries, design portfolio, and original media. Future study plans are excluded. Original application PDFs and private background information are not included in deployment. Project dates and disputed fundraising amounts are omitted. A source update to `content.js` is sufficient to add or revise a chapter.

## Validation

Verified desktop WebGL rendering, direct 3D building selection, project drawers, photo switching, directory search, and layout. The car path boundary was repaired and checked with repeated curve sampling. Desktop presentation is the current priority.
